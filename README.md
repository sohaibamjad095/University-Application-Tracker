# University Application Tracker

A smart web app to manage university applications.

## Features
- Add/Edit/Delete universities
- Deadline tracking
- Priority system
- Admission chance calculator
- Search & filter
- CSV export
- Dark mode
- Local storage saving

## Tech Stack
HTML, CSS, JavaScript
